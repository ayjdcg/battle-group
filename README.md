# 现代战争经营游戏 Demo

## 项目定位

这是一个围绕 **自动战斗、战役地图、主城经营** 展开的现代战争游戏原型。

玩家负责组建兵团、选择战线、指定战役目的地，并在后方组织生产和补充；单位自行完成寻路、选敌和具体战斗。核心乐趣来自编组、部署、路线和长期资源取舍，而不是传统 RTS 式的高频微操。

开发主线固定为：

```text
自动战斗
→ 战役地图
→ 主城经营
```

当前处于“自动战斗与战役地图闭环”阶段，主城系统尚未开始。

## 运行

项目没有第三方依赖和构建步骤。

- 打开 `index.html`：运行当前完整 Demo；
- 打开 `map-generator-demo.html`：只预览地图生成结果；
- 执行 `node campaign-core.test.js`：运行核心规则测试。

## 当前玩法

1. 输入地图种子和地图规模，生成一张三线战役地图；
2. 选择左侧蓝方单位；
3. 点击一个可达节点，为它指定目的地；
4. 至少部署一个单位后开始战役；
5. 敌军自动向蓝方司令部推进；
6. 双方在节点或通路相遇后自动战斗；
7. 蓝方夺取红方战役目标获胜；敌军进入蓝方司令部或蓝方全损时失败。

相同种子会生成相同地图。行军由节点和通路构成的图决定，画布坐标只负责显示。

## 当前实现边界

目前地图上的可控对象仍是单个作战单位，而不是正式兵团。这是用于验证行军、遭遇和自动战斗的临时实现。

已经实现：

- 确定性三线地图生成；
- 双向与单向通路；
- 自动寻路和连续行军；
- 节点战与通路遭遇战；
- 简化的兵种克制、治疗和胜负判定；
- 地图连通性、移动命令和遭遇战测试。

尚未实现：

- 兵团编组与兵团级命令；
- 地形、节点容量、通路容量和移动代价结算；
- 驻守、撤退、增援和脱离战斗；
- 战后损失与跨战役状态；
- 主城、生产、资源、补给和自动补充。

战术区域和画区指挥已经退出规划，不属于当前玩法。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 当前战役 Demo 入口。 |
| `map-generator.js` | 地图数据生成、图结构定义与校验。 |
| `campaign-core.js` | 寻路、命令、行军、战斗和胜负规则。 |
| `campaign-ui.js` | 输入、Canvas 渲染和界面更新。 |
| `campaign-core.test.js` | 核心规则测试。 |
| `map-generator-demo.html` | 独立地图预览页面。 |
| `战争经营游戏 Demo 开发说明.md` | 游戏方向、术语和阶段路线。 |
| `地图生成器设计.md` | 当前地图、行军和战斗规则的详细说明。 |

`tactics.js` 是已经放弃的战术区域原型遗留代码，当前入口不会加载它；后续做代码清理时可以删除。
