# 现代战争经营游戏 Demo

## 项目定位

这是一个围绕 **自动战斗、战役地图、主城经营** 展开的现代战争游戏原型。

玩家负责组建兵团、选择战线、指定战役目的地，并在后方组织生产和补充；单位自行完成寻路、选敌和具体战斗。核心乐趣来自编组、部署、路线和长期资源取舍，而不是传统 RTS 式的高频微操。

开发主线固定为：

```text
自动战斗
→ 战役地图
→ 主城经营
```

当前处于“自动战斗与战役地图闭环”阶段，主城系统尚未开始。

## 运行

项目使用 Vite 提供本地开发服务器，游戏逻辑仍为原生 JavaScript。

- 执行 `npm install`：安装开发依赖；
- 执行 `npm run dev`：启动完整 Demo，并在终端显示的本地地址访问；
- 执行 `npm test`：运行核心规则测试；
- 执行 `npm run build`：生成可部署的静态文件到 `dist/`；
- `map-generator-demo.html`：在开发服务器地址后直接访问该页面，仅预览地图生成结果。

## 当前玩法

1. 输入地图种子和地图规模，生成一张三线战役地图；
2. 选择左侧蓝方单位；
3. 在“测试编组与行军”中调整每支蓝方兵团的 9 个单位槽；可新增至 6 支测试兵团，并为每支兵团预设目标；
4. 也可选择左侧兵团后直接点击可达节点，修改它的行军目的地；
5. 至少给一支兵团下达行军命令后开始战役；
6. 测试 AI 会把敌军集结到中央线，并严格沿中央线向蓝方司令部推进；
7. 双方在节点或通路相遇后自动战斗；
8. 蓝方夺取红方战役目标获胜；敌军进入蓝方司令部或蓝方全损时失败。

相同种子会生成相同地图。行军由节点和通路构成的图决定，画布坐标只负责显示。

## 当前实现边界

地图上的可控对象是兵团。每支兵团最多容纳 9 个作战单位；玩家下达目的地、驻防和撤退命令，兵团内部单位自动行军、展开和战斗。

已经实现：

- 确定性三线地图生成；
- 双向与单向通路；
- 自动寻路和连续行军；
- 测试阶段的多兵团编组器：可增减每个兵种，单支兵团最多 9 槽，并可在开战前为多支兵团预设行军目标；
- 中央线测试 AI：红方先集中到中央线目标，随后使用固定中路路径推进，不会利用侧翼通路偷袭司令部；
- 节点战与通路遭遇战；
- 逐单位冷却、兵种克制、医疗和士气结算；
- 自动战斗成型：坦克与突击步兵进入前列，火力与反坦克单位进入支援列，医疗与防空留在后卫，直升机处于空中层；
- 前列掩护后方地面单位，以及战斗视图中的攻击/治疗连线；
- 节点容量限制每方实际投入的前线兵团数，其他兵团作为预备队；
- 地图连通性、移动命令和遭遇战测试。

尚未实现：

- 玩家可手动指定单个单位的站位或战斗姿态；
- 通路容量造成的行军拥堵与通路遭遇战后的路线续行；
- 更完整的地形效果、侦察和维修；
- 战后损失与跨战役状态；
- 主城、生产、资源、补给和自动补充。

## 当前测试流程

这是纯战斗验证工具，并不代表正式的生产或补给流程。生成地图后，先在左侧“测试编组与行军”中为每个蓝方兵团加减单位；每次调整会重建尚未开战的测试局并重新计算预设路线。目标下拉框可一次性给多支兵团排定开战路线；也可以用地图点击改写当前选中兵团的目标。

点击“开始战役”后，编组器锁定以保证战斗数据一致。红方三个守备兵团会移至敌方中央线目标，并按中央线节点从红向蓝推进；它们不会经过北线或南线的横向连接。这样玩家可以专注比较不同蓝方编制、中央线阻击和增援路线。补给、自动补充、生产成本均仍未进入本阶段。

战术区域和画区指挥已经退出规划，不属于当前玩法。

## 当前自动战斗规则

P1 的战斗刻意不含补给、弹药或自动补充；这些会在无补给战斗足够稳定、有趣后才作为后勤循环加入。当前的站位由系统自动决定，不要求玩家拖拽九宫格：

| 层级 | 自动部署单位 | 规则作用 |
| --- | --- | --- |
| 前列 | 坦克、突击步兵 | 优先承受地面攻击，并掩护后方。 |
| 支援列 | 机枪组、榴弹兵、反坦克班 | 隔着己方前列输出；敌方前列未被击溃前不会成为普通地面火力的优先目标。 |
| 后卫 | 医疗兵、防空班 | 医疗兵治疗全兵团最危急的伤员；防空班专门攻击直升机。 |
| 空中层 | 攻击直升机 | 不受普通地面单位攻击，优先猎杀坦克。 |

战斗以较慢节奏运行：伤害缩放为基础数值的 65%，攻击与治疗冷却延长至基础值的 1.8 倍。战斗窗口直接显示单位图标、当前生命和即时连线：橙线为攻击、绿虚线为治疗，线宽表示本次作用强度。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 当前战役 Demo 入口。 |
| `map-generator.js` | 地图数据生成、图结构定义与校验。 |
| `campaign-core.js` | 寻路、命令、行军、战斗和胜负规则。 |
| `campaign-ui.js` | 输入、Canvas 渲染和界面更新。 |
| `campaign-core.test.js` | 核心规则测试。 |
| `map-generator-demo.html` | 独立地图预览页面。 |
| `战争经营游戏 Demo 开发说明.md` | 游戏方向、术语和阶段路线。 |
| `地图生成器设计.md` | 当前地图、行军和战斗规则的详细说明。 |
| `战斗深化设计.md` | 前线/预备队、接替、突破、节点价值与操作逻辑的讨论稿。 |

`tactics.js` 是已经放弃的战术区域原型遗留代码，当前入口不会加载它；后续做代码清理时可以删除。
